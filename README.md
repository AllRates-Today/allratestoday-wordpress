# AllRatesToday Currency Converter — WordPress plugin

Source of the [AllRatesToday Currency Converter](https://wordpress.org/plugins/allratestoday-currency-converter/) plugin: a currency converter block and an official central-bank exchange rate block, with matching shortcodes. No API key needed.

The plugin lives in [`allratestoday-currency-converter/`](allratestoday-currency-converter/). See its [`readme.txt`](allratestoday-currency-converter/readme.txt) for features, shortcodes and the external-service disclosure.

## Build the upload zip

```bash
zip -r allratestoday-currency-converter.zip allratestoday-currency-converter
```
